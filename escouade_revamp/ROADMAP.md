# 🗺️ Roadmap — Escouade

JDR de rôle fantasy en temps réel (inspiré de Final Fantasy).
Architecture front / back séparés. Moteur de jeu en TypeScript (Node/Express/Socket.IO/Mongoose).

## État des lieux

**Solide** : types partagés, 6 classes (`Job` + implémentations), `Character`/`Unit` (pathfinding Dijkstra, cibles), `Zone`, `ActionManager`, données JSON, auth REST + Socket.IO, tests Jest.

**À écrire (fichiers vides / squelettes)** :
- Module **Combat** : `BattleManager`, `CombatState`, `PhaseSystem`
- **Exploration** : `EncounterEngine`, `ExplorationState`, `Party`
- **Services** : `AIService`, `CombatService`, `ExplorationService`, `LootService`, `HubService`, `NPCService`, `QuestService`, `CampfireService`
- `SpawnService` (squelette)
- **Tout le front**
